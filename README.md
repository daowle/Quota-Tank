# QuotaTank

Claude / Codex(ChatGPT) / Gemini 구독의 5시간·주간 한도를 보여 주는 데스크톱 위젯(Windows·macOS). 오픈소스([MIT](LICENSE)).

- 이 PC 의 CLI 로그인(Claude Code·Codex·Antigravity)으로 각 서비스의 사용량을 조회한다. 로그인 정보는 PC 밖의 다른 곳으로 보내지 않는다([데이터 처리 안내](PRIVACY.md), [보안 경계](SECURITY.md)).
- 사용량 조회 API 는 각 서비스의 **공식 공개 API 가 아니다**. 서비스 쪽이 바꾸면 언제든 동작하지 않을 수 있다. 이 앱은 OpenAI·Anthropic·Google 의 공식 제품이 아니다.
- 버그·제안은 Issues 로 받는다. 로그인 파일·토큰·대화 기록은 첨부하지 않는다.

## 설치

[Releases](https://github.com/daowle/Quota-Tank/releases/latest)에서 내 OS 파일을 받는다. 아직 코드 서명을 하지 않아 처음 한 번은 OS가 경고를 띄운다.
새 버전이 나오면 위젯이 알려 준다(하루 한 번 GitHub 최신 릴리스 번호만 확인, 자세히 보기 아래 **새 버전** · 트레이 메뉴). 자동으로 설치하지는 않는다. 끄려면 `config.json` 의 `update_check` 를 `false` 로.
받은 파일이 릴리스에 올라온 파일과 같은지는 함께 올라온 `.sha256` 값으로 확인할 수 있다.

### Windows 10 / 11 — `QuotaTank-windows.exe`
1. 브라우저가 "일반적으로 다운로드되지 않는 파일"이라고 하면 `…` → **유지**를 누른다.
2. 실행하면 "Windows의 PC 보호" 창이 뜬다. **추가 정보** → **실행**을 누른다. 다음부터는 묻지 않는다.
3. 설치 과정 없이 바로 뜬다. 원하는 폴더에 옮겨 두고 쓴다. WebView2 런타임이 필요하다(윈도우 11에는 기본 포함, 10은 [여기](https://developer.microsoft.com/microsoft-edge/webview2/)에서 설치).

확인: PowerShell에서 `Get-FileHash .\QuotaTank-windows.exe` 값이 `.sha256` 파일과 같은지 본다.

### macOS (Apple Silicon)
**터미널에 한 줄 붙여넣기(추천)** — 받기, SHA-256 확인, 응용 프로그램 폴더에 설치, 실행까지 한 번에 한다. 경고 창이 뜨지 않는다.
```
curl -fsSL https://raw.githubusercontent.com/daowle/Quota-Tank/main/install.sh | bash
```
같은 명령으로 새 버전으로 업데이트한다. 실행되면 Dock 에는 뜨지 않고 **화면 오른쪽 위 메뉴 막대**에 사용률이 보인다.

**브라우저로 `QuotaTank-mac-arm64.zip` 을 받은 경우**: Apple 공증 전이라 macOS 가 더블클릭 실행을 막는다.
1. 압축을 풀고 `QuotaTank.app`을 **응용 프로그램** 폴더로 옮긴다.
2. 앱을 열면 "확인할 수 없음" 경고가 뜬다. **완료**를 누른다(휴지통으로 이동 X).
3. **시스템 설정 → 개인정보 보호 및 보안**을 열고 **맨 아래 "보안" 칸까지 스크롤**해 **그래도 열기**를 누른다(앱을 열어 본 뒤 1시간 안에만 보인다).

버튼이 보이지 않으면 터미널에서 `xattr -dr com.apple.quarantine /Applications/QuotaTank.app` 를 한 번 실행한다.
Intel 맥용 빌드는 아직 없다(소스로 실행: [맥에서 쓰기](#맥에서-쓰기)).

### 처음 실행
처음 켜면 **QuotaTank 시작하기** 화면이 뜬다. 이 PC에서 찾은 Claude·Codex 로그인과, 함께 연결할 수 있는 다른 계정(`~/.claude-이름` 등)이 보인다. Gemini 보기·시작 시 실행·한도 리셋 알림을 고른 뒤 **이대로 시작**을 누르면 한 번에 설정된다. **직접 설정할게요**를 누르면 아무것도 바꾸지 않는다. 이 화면은 한 번만 뜬다(설정 파일 `onboarded`). 이 기능이 생기기 전부터 쓰던 사용자에게는 뜨지 않는다. 스토어(MSIX) 설치본은 시작 시 실행을 윈도우 설정에서 켜므로 그 줄이 없다.

## 여러 계정 연결

- 자세히 보기 맨 아래의 **계정 추가** 줄을 누르면 계정 추가 화면이 바로 열립니다. 이 PC에 아직 연결하지 않은 로그인이 있으면 줄에 "이 PC에서 찾은 로그인 N개"가 보입니다. **계정 관리**는 그 아래, 업데이트 시각 옆에 있습니다(둘 다 간단히 보기에는 없습니다).
- 자세히 보기의 카드 이름표(Pro·Plus·Gemini 등)는 토글입니다. 끄면 이름표가 점선으로 흐려지고 간단히 보기에서 그 링이 빠집니다(마지막 하나는 끌 수 없음). `config.json`의 `compact_hidden`에 저장됩니다.
- 계정 관리 화면은 버튼만으로 씁니다. 목록 한 줄이 카드 하나이고, 줄마다 **↑ ↓**(순서), **연필**(이름 수정), **휴지통**(삭제) 버튼이 있습니다. 기본 Claude·Codex는 삭제할 수 없습니다. Gemini는 Antigravity가 로그인 정보를 한 곳에만 두어 계정 하나만 볼 수 있습니다.
- **계정 추가** 화면 맨 위에는 이 PC에서 찾았지만 아직 연결하지 않은 로그인(`~/.claude-이름` 같은 폴더)이 나오고, **연결**을 한 번 누르면 붙습니다. 새로 로그인하려면 아래에서 Claude / Codex / Gemini 중 하나를 고릅니다. Claude·Codex는 고르는 즉시 공식 로그인(`claude auth login` / `codex login`)이 브라우저에 열립니다. 터미널 창은 뜨지 않습니다. 추가할 계정으로 로그인을 마치면 자동으로 연결됩니다. Gemini는 고르면 바로 켜집니다(Antigravity 로그인 필요). 이름은 로그인한 이메일로 들어가고 목록에서 바꿉니다.
- 로그인은 새 설정 폴더(`~/.claude-이름`, `~/.codex-이름`)에 저장돼 기존 로그인과 섞이지 않습니다(`CLAUDE_CONFIG_DIR` / `CODEX_HOME`). 이 폴더는 CLI에서도 그대로 쓸 수 있습니다 — 예: `CLAUDE_CONFIG_DIR=~/.claude-회사 claude`.
- Claude 추가 계정의 토큰은 약 8시간마다 갱신이 필요합니다. 그 계정으로 Claude Code를 쓰면 저절로 갱신되고, 오래 안 쓰면 카드에 "토큰 만료"가 뜹니다(Codex 토큰은 열흘가량 유지).
- 홈 폴더에 이미 다른 설정 폴더(`~/.claude-*`, `~/.codex-*`)로 로그인해 둔 계정이 있으면, 브라우저 로그인이 안 됐을 때 그 이메일이 버튼으로 보이고 누르면 바로 연결됩니다.
- 기본 계정이나 이미 연결한 계정과 같은 이메일로 로그인하면 중복으로 막습니다. 설정에는 파일 경로·이름·이메일만 저장하고 토큰은 복사하지 않습니다.
- 브라우저 로그인이 안 됐을 때 나오는 **파일에서 선택**으로 `.credentials.json`(Claude) / `auth.json`(Codex)을 직접 연결할 수도 있습니다.
- 맥: 기본 Claude 계정 조회는 지원합니다. Claude 추가 계정의 브라우저 로그인은 현재 코드에서 차단하며, 추가 키체인 프로필 연결은 구현하지 않았습니다(Codex 추가 로그인은 지원). 별도 `.credentials.json` 파일 직접 연결 경로는 있지만 macOS 실기 검증은 하지 않았습니다.
- 추가 계정은 별도 사용량 카드·리셋 알림을 제공하며 계정 관리 목록의 **휴지통 → 삭제**로 제거할 수 있습니다(PC의 로그인 폴더는 지우지 않아 다시 연결할 수 있습니다). 인사이트 화면은 기본 계정, 터미널 자동 이어 가기는 작업 계정(아래) 기준입니다. 계정 관리 UI는 pywebview 화면에서 지원합니다.

### 작업 계정 바꾸기 (윈도우)

그냥 `claude` / `codex` 를 실행했을 때 쓸 계정을 고릅니다. 터미널을 닫지 않아도 됩니다.

- 계정 관리 목록에서 Claude·Codex 줄 왼쪽의 **동그라미**를 누릅니다. 서비스마다 하나가 채워져 있고, 그 줄에 "작업 계정"이 붙습니다. 처음에는 기본 계정입니다.
- **Claude**: 열려 있는 Claude Code(터미널·VS Code 확장)도 다음 메시지부터 바꾼 계정을 씁니다. 바로 바꾸고 싶으면 Claude Code만 다시 실행합니다.
- **Codex**: 실행 중인 Codex(CLI·VS Code 확장·앱)를 모두 끝낸 뒤 바꿉니다. 켜져 있으면 바꾸지 않고 알려 줍니다. 바꾼 뒤 같은 터미널에서 `codex` 를 다시 실행하면 됩니다.
- 위젯은 기본 로그인 자리(`~/.claude`, `~/.codex`)와 그 계정 폴더(`~/.claude-이름` 등)의 로그인만 맞바꿉니다. 원래 기본 계정의 로그인은 그동안 그 폴더에 맡겨 둡니다(`.quotatank-default` 표시 파일). 토큰을 복사하지 않아 같은 로그인이 두 곳에 남지 않습니다.
  Claude 는 MCP 로그인·설정·프로젝트·대화 기록을 바꾸지 않고 계정만 바꿉니다.
- 카드와 사용량 기록은 계정을 따라갑니다. 사이클 예약·켤 때 Claude 시작·자동 이어 가기는 작업 계정의 카드를 봅니다.
  비용 집계·공유 사용량 나누기·인사이트는 이 PC 의 Claude Code 기록 전체를 읽으므로 계정을 바꿔 쓴 만큼 섞입니다.
- 작업 계정으로 고른 추가 계정은 삭제할 수 없습니다(원래 기본 계정의 로그인이 그 폴더에 있습니다). 다른 계정을 고른 뒤 삭제하세요.
- 그 계정 폴더를 `CLAUDE_CONFIG_DIR` / `CODEX_HOME` 으로 직접 지정해 따로 실행하면, 바꾸는 동안에는 원래 기본 계정으로 돕니다.
- 바꾸는 중에 PC 가 꺼져도 다음에 위젯을 켜면 남긴 기록대로 마저 바꿉니다.
- 한계: Claude Code 가 바뀐 로그인 파일을 다시 읽는 동작은 공식 문서에 없고 [claude-swap](https://github.com/realiti4/claude-swap) 의 분석을 따른 것입니다. Claude Code 가 바뀌면 동작이 달라질 수 있습니다. 맥은 아직 지원하지 않습니다. 계정 여러 개를 번갈아 쓰는 것이 각 서비스 약관에 맞는지는 직접 확인하세요.

## 개발과 배포

앞으로 할 일은 [개발 계획](ROADMAP.md)에 있다. 코드를 고칠 때의 규칙(보안 경계·테스트·커밋)은 [AGENTS.md](AGENTS.md), 릴리스 순서는 [배포 안내](DISTRIBUTION.md).

### 실행파일 빌드
- 윈도우: `pip install -r requirements.txt pyinstaller` 후 `pyinstaller widget.spec` → `dist/QuotaTank.exe` 하나(설치 없음, WebView2 런타임 필요 — 윈도우 11에는 기본 포함).
- 맥: 같은 명령 → `dist/QuotaTank.app` (Dock 에 안 뜨는 메뉴 막대 앱). 서명·공증 전에는 처음 열 때 [설치](#설치)의 "그래도 열기" 절차가 필요하다.
- `widget.py` 의 `VERSION` 과 같은 `v1.2.3` 태그를 올리면 `.github/workflows/release.yml`이 윈도우 exe·MSIX와 맥(Apple Silicon) zip을 빌드해 이 저장소의 초안 릴리스에 올린다([DISTRIBUTION.md](DISTRIBUTION.md)). 코드 서명·MSIX 설정은 [SIGNING.md](SIGNING.md).
- 실행파일과 소스 실행은 같은 잠금을 써서 둘이 동시에 뜨지 않는다(한쪽을 실행하면 다른 쪽이 꺼진다).

실행: `pythonw widget.py` 또는 바탕화면·시작 메뉴의 **QuotaTank** 아이콘

- 켜져 있을 때 한 번 더 실행하면 꺼진다(아이콘 클릭 = 켜기/끄기). 두 개가 뜨지 않는다.
- 켜져 있는 동안 작업 표시줄 오른쪽 아래 알림 영역에 아이콘이 뜬다(`pip install --user pystray`).
  왼쪽 클릭: 위젯 숨기기/보이기, 마우스 올리기: 사용률, 우클릭: 새로고침 / 인사이트 / 항상 위 / 시작 시 실행 / 종료.
  `^` 안에 숨어 있으면 설정 → 개인 설정 → 작업 표시줄 → 기타 시스템 트레이 아이콘에서 pythonw를 켠다.
  아이콘은 Claude · Codex · Gemini 순서의 막대 세 개로, 높이가 5시간 사용률이고 색이 여유(초록)·주의(노랑)·위험(빨강)이다.
- 맥 메뉴 막대: 아이콘 대신 `C 16%  X 18%  G 0%` 처럼 서비스별 5시간 사용률을 글자로 띄운다(글자색 = 서비스 색).
  메뉴 막대 아이콘 메뉴 → 메뉴 막대에 사용률 표시로 끄면 막대 아이콘만 남는다.
- 조회 간격: 서비스·계정마다 따로 정한다. 기본 5분(`poll_sec` 300초). 5시간이나 주간 사용률이 80% 이상이면 2분마다 본다. 리셋 시각 직후에는 바로 조회한다. 서버가 요청 많음(429)으로 답하면 2·4·8분 쉬고, 그 뒤 성공할 때마다 한 단계씩(8 → 4 → 2분 → 기본) 돌아온다. 예전 기본값 60초가 저장된 설정은 300초로 올린다.
  429(요청 많음)를 받은 곳은 2 → 4 → 8분으로 늘렸다가(서버가 더 기다리라면 그만큼, 최대 1시간) 성공하면 되돌린다.
  새로고침은 대기로 늦춘 곳도 바로 조회하지만, 429로 기다리는 곳은 건너뛴다(다시 요청하면 더 오래 막힌다).
- Claude 토큰 만료: Claude Code 토큰은 몇 시간이면 만료돼서, 밤새 꺼 둔 PC 를 켜면 대개 만료돼 있다. 만료된 토큰으로 조회하면 서버가 401 대신
  429(최대 1시간 대기)를 줘서 Claude Code 를 켠 뒤에도 조회가 막히므로, 만료된 동안은 요청하지 않고 마지막 기록을 보여 준다.
  Claude Code 를 켜거나 사이클 예약이 실행돼 토큰이 갱신되면 다음 조회(기본 1분) 때 최신 값으로 바뀐다.
- 서비스 장애: status.claude.com·status.openai.com 을 5분마다 보고, 장애·점검 중이면 카드 머리에 배지(간단히 보기는 링 위 점)를 띄운다.
  Claude는 claude.ai·Claude Code 상태만 반영하며, Console 등 다른 제품의 장애는 배지를 띄우지 않는다.
  마우스를 올리면 영향을 받는 기능의 상태 설명이 보인다. Gemini(Antigravity)는 공개된 상태 정보가 없어 빠진다.
- 처음 실행: Claude·Codex 링 두 개를 간단히 보기로 표시한다. Gemini는 기본 비활성화라 조회하지 않는다. 자세히 보기의 계정 추가(또는 우클릭 → 계정 관리 → 계정 추가) → Gemini에서 켜거나 끌 수 있고, 선택은 저장된다. 기존 보기·계정 설정은 유지한다.
- 계정 관리: 카드 순서 변경(↑ ↓, `config.json`의 `order`에 저장), 이름 수정(최대 40자, Enter 저장·Esc 취소. 기본 서비스 카드의 이름은 `names`에 저장), 삭제(휴지통을 누른 뒤 **삭제**로 확인)를 할 수 있다. 삭제해도 PC의 로그인 정보는 지우지 않는다. Gemini는 삭제하면 꺼지고 계정 추가에서 다시 켠다.
- 모델별 한도: 요금제에 모델별 주간 한도(예: Opus 주간)나 Codex 추가 한도가 있으면 주간 막대 아래에 따로 보인다.
  서버 응답의 기간으로 5시간·주간·기타 창을 구분하며, 모델별 고정 토큰 한도를 임의로 설정하지 않는다. Codex 주간 전용 계정은 5시간 창을 대기로 표시하지 않는다.
  서버가 5시간 창을 알려 주지 않으면(Claude Max 처럼 응답의 `five_hour` 가 비어 있을 때 등) 5시간 줄을 숨기고 주간 기준으로 바꾼다: 링의 굵은 고리와 숫자는 주간 사용률, 가는 고리는 오늘 쓸 몫을 얼마나 썼는지, 자세히 보기의 큰 글자는 "오늘 N%p 남음"이다.
- API 비용 환산: 2026-10-03 확인한 [OpenAI API Standard 단가](https://developers.openai.com/api/docs/pricing)와 [Anthropic 단가](https://platform.claude.com/docs/en/about-claude/pricing)를 적용한다. GPT-6.1 Sol은 입력 $2 / 캐시 읽기 $0.10 / 캐시 쓰기 $2.50 / 출력 $10, GPT-5.6 Sol은 $4 / $0.40 / $5 / $20 (각각 1M 토큰당).
  Codex 입력 토큰에는 캐시 토큰이 포함되어 있으므로 일반 입력과 캐시 읽기·쓰기를 분리한다. reasoning 토큰은 출력에 이미 포함되어 있어 다시 더하지 않는다. GPT-6·GPT-5.6은 로그의 마지막 요청 입력이 272K를 초과하면 입력·캐시 2배, 출력 1.5배로 환산한다. 이벤트 사이에 여러 요청이 누적되거나 기록이 빠진 경우 오차가 있을 수 있다.
  현재 Standard 기준 추정치이며 Fast·Ultrafast, 지역 할증, 별도 도구 요금은 포함하지 않는다. 확인되지 않은 모델은 토큰만 집계한다. 추가 계정의 별도 프로필 기록은 현재 비용 집계에 포함하지 않는다. 시작 시 기존 비용 캐시도 다시 집계한다.
- 리셋 알림: 5시간·주간 창을 `reset_alert_min`%(기본 80) 이상 쓴 채로 리셋 시각이 지나면
  `web/reset.wav` 알림음과 알림이 뜬다. 트레이 우클릭 → 리셋 알림음으로 끄고 켠다.
- 리밋 풀리면 Claude 이어 가기(윈도우): 터미널(VS Code 터미널·Windows Terminal)에서 돌던 Claude Code 세션이
  리밋 에러로 멈춰 있으면, 리셋 시각에 맞춰(보통 1~3초 안. 새로 조회해 한도가 풀린 것을 확인한 다음) 그 터미널에 `resume_text`(기본 "continue")와 Enter 를 넣는다.
  창을 앞으로 가져오거나 포커스를 뺏지 않는다(콘솔 입력 버퍼에 직접 쓴다). `~/.claude/sessions/<pid>.json` 으로
  실행 중인 프로세스와 세션을 잇고, 대화 기록의 마지막 항목이 리밋 에러일 때만 보낸다.
  VS Code 확장 패널·Codex 확장/데스크톱 앱은 콘솔이 없어 대상이 아니다(확장 패널은 아래 "한도가 풀리면 이어 가기"를 본다). 트레이 우클릭 → 리밋 풀리면 Claude 이어 가기로 끄고 켠다.

- 화면은 pywebview(Edge WebView2)로 그린다: `pip install --user pywebview`
- pywebview가 없거나 `pythonw widget.py --tk`로 실행하면 예전 Tk 화면(표준 라이브러리만)으로 뜬다.

## 화면 읽는 법
- 색: 화면은 검정·흰색·회색만 쓰고, 링·막대·큰 숫자·작은 표식의 색이 서비스를 나타낸다(주황 Claude, 청록 Codex, 파랑→보라 Gemini). 5시간이나 주간 사용률이 85% 이상이면 큰 숫자 옆에 빨간 점과 "한도 가까움"(간단히 보기는 링 왼쪽 위 빨간 점)이 뜬다. 빨강은 이 표시와 오류에만 쓴다.
- 간단히 보기: 바깥 링 = 5시간, 안쪽 얇은 링 = 주간, 흰 눈금 = 5시간 창의 시간 경과율.
- 자세히 보기: 맨 위 점 줄은 5시간 사이클 시작 시각(채운 점 = 오늘 실제 시작, 빈 점 = 다음에 시작할 수 있는 시각).
  막대가 눈금을 앞지르면 과속(빗금). 맨 아래 그래프의 점선은 최근 90분 속도로 그은 예상선.
- 주간 예측: 이번 주 평균 속도로 리셋 전에 한도에 도달하면 `주간 10/4(토) 15:00 소진 예상`을 빨갛게 보여 준다.
  바로 아래에 소진까지 남은 시간, 주간 페이스, 오늘 쓸 몫(%p)을 표시한다. 여유가 있으면 리셋 때 예상 사용률을 표시한다.
  오늘 쓸 몫은 하루 기준 시각(`day_reset_hour`, 기본 오전 6시)의 주간 사용률에서 남은 한도를 리셋까지 남은 날수로 나눈 값이다. 하루 동안 고정이라 쓰는 만큼만 줄고, 다음 기준 시각에 새로 계산한다. 리셋이 그 전이면 남은 한도 전부가 오늘 몫이다. 그날 기준 시각 전 기록이 없으면 오늘 첫 기록에서 출발한다.
  첫 12시간은 예측 준비 중으로 표시하며, 이전 기록에는 최신 사용량 확인이 필요하다고 표시한다. 마우스를 올리면 평균 속도 기준과 주간 리셋 시각을 확인할 수 있다.
  휴식·사용 패턴 변화나 요금제 변경은 미리 반영하지 못하므로 예상 시각은 실제 사용에 따라 달라진다.
  Claude 카드의 '크레딧' 줄은 클라우드 세션(Claude Code on the web) 크레딧 칸. 데이터가 없거나 기간이 지나면 줄째로 사라진다
  (`providers/claude.py`의 `cloud_credit()`가 `{"used_pct", "text", "r"}`를 돌려줄 때만 보이고, `r`(만료 시각)이 지나면 다시 숨는다).
- 인사이트: 자세히 보기 창과 같은 크기, 탭 세 장(←/→ 키·가로 스와이프로도 넘김). 패턴 = 사이클 통계·시작 시각 히트맵, 사용률 = 사이클별 최고 사용률 분포·팁,
  비용 = 최근 30일 Claude Code·Codex 토큰을 API 단가로 환산한 금액(날짜별·모델별). 구독 요금과 별개인 추정치이고, 단가를 모르는 모델은 토큰만 센다.

## API 크레딧 (Max·Ultra, 기본 꺼짐)

Max·Ultra 요금제는 매달 Claude API 크레딧(Max 100달러, Ultra 200달러)을 준다. 결제 주기가 끝나면 남은 크레딧은 사라진다(다음 달로 넘어가지 않는다). Claude Code 에는 쓸 수 없고 API·Agent SDK·Console 플레이그라운드에 쓴다.
- 계정 관리 → **API 크레딧**에서 **결제일**(1~31, 비우면 끔)과 **한 달 크레딧**($100 / $200)을 정하면 자세히 보기에 API 크레딧 카드가 생긴다. 사라지는 날까지 남은 날을 보여 주고, 3일 전·하루 전에 트레이로 알린다.
- **관리자 키**(Console 조직의 Admin API 키, `sk-ant-admin…`)를 넣으면 이번 주기에 쓴 금액(비용 보고서)을 30분마다 불러와 남은 금액과 "하루 얼마씩 쓰면 다 쓰는지"를 보여 준다. 남은 금액이 5달러 미만이면 알리지 않는다. Admin API 는 개인 조직(Individual Org)에서는 쓸 수 없어서 Console 설정 → 조직에서 **팀으로 전환**한 뒤 Settings → Admin keys 에서 만든다. 비용 보고서는 몇 분 늦게 쌓이고 하루 단위(UTC)라 결제일 당일 사용분은 조금 다를 수 있다.
- 키가 있으면 인사이트 → **비용** 탭 맨 위에 이번 주기의 날짜별 API 사용 금액(UTC 날짜) 막대가 생긴다.
- 키는 윈도우 자격 증명 관리자·맥 키체인에만 저장하고, **지우기**로 지운다(SECURITY.md).

## 공유 사용량 나눠 보기 (Claude, 기본 꺼짐)
Claude 구독을 다른 사람과 같이 쓸 때, 5시간·주간 사용률 중 **이 PC 에서 내가 쓴 몫**과 **다른 곳(다른 사용자·다른 기기)의 몫**을 나눠 보여 준다.
상대가 여러 명이어도 합산한 "다른 곳" 하나로 보인다. 우클릭 메뉴 또는 트레이의 **공유 사용량 나눠 보기**로 켠다. 켜면 Claude 카드의 5시간·주간 막대에서 이 PC 에서 쓴 몫이 보라색으로 칠해지고, 그 끝을 내림 세모(▼)가 가리키며 양 옆에 퍼센트(왼쪽 = 내 몫, 오른쪽 = 나머지)가 작게 붙는다. 5시간 그래프에는 내 몫 곡선이 보라색으로 겹쳐 그려진다. 인사이트의 사용률 탭에는 5시간 창별 나누기가 생긴다.

- **원리**: 서버는 사용률(%)만 알려 주고 토큰 수는 주지 않는다. 이 PC 의 Claude Code 기록에서 창 시작부터 쓴 토큰을 API 단가로 환산한 금액에
  환산 계수(사용률 %p / 1달러)를 곱한 것이 내 몫이고, 서버 사용률에서 내 몫을 뺀 나머지가 다른 곳이다.
- **요금제**: 서버는 Max 5배와 20배를 구분해 알려 주지 않는다. 메뉴의 **요금제**에서 고른다(기본 자동: Pro 가 아니면 5배로 본다). 틀리면 내 몫이 5배·20배 단위로 틀린다.
- **환산 계수**: 기본값은 Pro 를 혼자 쓴 실측값을 요금제 배수로 나눈 것이다. 기능을 끈 채 쓰는 동안은 혼자 쓴다고 보고 끝난 창마다 계수를 배운다(비율이 낮은 쪽 20% 값).
  나 혼자 쓴 창에서 메뉴의 **나만 썼어요(5시간/주간)**를 누르면 그 창의 비율로 맞춘다. 직접 맞춘 값이 가장 우선하고 **직접 맞춘 값 지우기**로 되돌린다.
- **한계**: 추정치다(Pro 혼자 쓴 기록에서 오차는 0~4%p 였다). 내가 다른 PC·폰·웹에서 쓴 양은 "다른 곳"에 들어간다. Max 의 배수와 Opus 가 아닌 모델(Fable 등)의 가중치는 실측하지 못했다.
  Anthropic 소비자 약관은 계정 공유를 허용하지 않으므로, 약관이 허용하는 방식(예: 팀·Enterprise 좌석)으로 쓰는지는 사용자가 확인한다.
- 추가 계정과 Codex·Gemini 는 대상이 아니다. 새로 읽는 파일·외부 요청은 없다(이미 비용 집계가 읽는 Claude Code 기록과 위젯 자체 기록만 쓴다).
- 설계·실측: [docs/plans/shared-usage-split.md](docs/plans/shared-usage-split.md), 실제 기록으로 계수를 보는 도구: `python tools/share_probe.py`

## 사이클 예약 (Claude, 기본 꺼짐)

5시간 창은 첫 메시지를 보낸 때부터 돈다. 정한 시각에 위젯이 한 마디를 대신 보내 창을 그때 시작해 두면, 일을 시작할 무렵에 창이 얼마 남았는지·언제 다시 차는지를 원하는 대로 맞출 수 있다.

- 우클릭 메뉴(또는 트레이)에서 **사이클 예약 (Claude)** 을 켜고, **시작 시각** 칸에 `08:00, 13:00` 처럼 적는다(하루 4개까지, 매일 반복).
- 그 시각에 Claude 의 5시간 창이 쉬고 있을 때 보낸다. 이미 창이 돌고 있거나 주간 한도가 찼으면 보내지 않는다(위젯이 사용량을 받지 못해 상태를 모를 때는 보낸다).
- 5시간 한도가 없는 계정(2026-11 기준 Claude Max)은 시작할 창이 없으므로 보내지 않는다. 메뉴의 시작 시각 칸 아래에 그렇다고 표시된다.
- 시각을 적거나 기능을 켠 때가 예약 시각 뒤 10분 안이면 곧바로 보낸다.
- PC 가 꺼져 있거나 잠들어 예약 시각을 10분 넘게 놓치면 그날 그 예약은 건너뛴다(엉뚱한 시각에 창을 열지 않는다).
- 보내는 방법: 이미 로그인된 공식 Claude Code CLI 를 빈 임시 폴더에서 한 번 실행한다
  (`claude -p hi --safe-mode --model haiku --no-session-persistence --tools ""`). 가장 작은 모델에 한 마디라 사용량은 아주 조금 든다.
  위젯은 로그인 정보를 읽거나 넘기지 않고, 열려 있는 터미널·편집기에는 아무것도 입력하지 않는다.
- 보낸 뒤 바로 사용량을 다시 조회해 새 리셋 시각을 보여 주고 알림을 띄운다. Claude Code 가 설치돼 있지 않거나 로그인이 풀렸으면 실패 알림이 뜬다.
- **한계**: 한 마디로 창이 시작되는지는 서비스 쪽 규칙에 달려 있다(공식 문서에 시작 규칙이 적혀 있지 않다). 시작됐는지는 알림 뒤 위젯의 리셋 시각으로 확인한다. Codex·추가 계정은 아직 대상이 아니다.
- **PC 가 꺼져 있어 놓쳤을 때**: 켠 뒤(또는 깨운 뒤) 그날 놓친 예약이 있으면 한 번 알리고, PC 없이 도는 Claude Code 클라우드 루틴을 권한다
  (Claude Code 에서 `/schedule` 로 매일 그 시각쯤 "hi" 를 보내는 루틴, 또는 claude.ai/code/routines). 공식 문서에 따르면 루틴도 구독 사용량에 잡히고,
  정각 예약은 몇 분 늦게 돌 수 있으며, 간격은 1시간 이상이어야 한다. 루틴 한 번이 5시간 창을 여는지는 문서에 없어 확인하지 못했다.

### 켤 때 Claude 시작 (기본 꺼짐)
- 우클릭 메뉴(또는 트레이)의 **켤 때 Claude 시작**. PC 를 켜거나 잠에서 깨운 뒤 10분 안에 Claude 토큰이 만료돼 있으면, 사이클 예약과 같은 방법으로
  공식 CLI 에 한 마디를 한 번 보낸다. CLI 가 토큰을 갱신하므로 위젯이 바로 최신 사용량을 보여 주고, **5시간 창이 있는 요금제면 창도 그때 시작된다.**
- 켤 때(깨울 때)마다 한 번만 보낸다. 토큰이 아직 살아 있으면 보내지 않는다. 위젯은 토큰을 직접 갱신하지 않는다(Claude Code 로그인이 풀릴 수 있어서).

## 한도가 풀리면 이어 가기

- **Claude Code 자체 기능(권장, VS Code 확장 패널 포함)**: Claude Code 설정 `autoContinueAtUsageLimit`(`/config` 의 "Continue automatically at usage limit")를 켜면 한도로 멈춘 세션이 리셋을 기다렸다가 스스로 이어 간다. `~/.claude/settings.json` 에 `"autoContinueAtUsageLimit": true` 로 적어도 된다.
- **위젯의 자동 이어가기(Windows, 터미널 세션)**: 아래 "데이터"의 `auto_resume`. Claude Code 가 스스로 이어 갔으면 위젯은 건너뛴다.
- **VS Code 확장 패널에도 넣기(Windows, 실험, 기본 꺼짐)**: 트레이 우클릭 → "└ VS Code 패널도"로 켠다(`panel_resume`, 위의 자동 이어가기가 켜져 있어야 한다).
  패널에는 터미널처럼 바깥에서 글을 넣는 통로가 없어서 키 입력으로 보낸다. 그래서 조건이 모두 맞을 때만 한다.
  - **4분 이상 키보드·마우스를 안 쓰고, 화면이 잠기지 않았고, 발표·전체 화면·화면 보호기 상태가 아닐 때만** 한다. 한도가 풀린 지 6시간이 넘은 세션에는 넣지 않는다. 자리에 있으면 비울 때까지 기다린다.
  - 그 세션의 폴더를 연 편집기 창(제목의 폴더 칸이 그 폴더 이름인 창이 정확히 하나)을 앞으로 띄우고 그 세션의 패널을 연다. 편집기 창이나 패널 세션이 여럿이어도 된다.
    윈도우가 창을 앞으로 가져오게 두지 않으면 아무것도 열지 않고 그만둔다.
  - 포커스가 비어 있는 Claude 입력창(`Message input`)이고, 그 패널 끝에 이 세션을 멈춘 한도 안내의 리셋 시각(`resets 3:45pm`)이 보일 때만 글자를 넣는다
    (윈도우 UI Automation 으로 확인, 화면 프로세스가 PowerShell 을 띄운다). 한도 안내에 리셋 시각이 없으면 확인할 수 없어 넣지 않는다.
  - Enter 직전에 입력창에 정확히 그 글자만 있고 같은 창이 앞에 있는지 다시 보고, 어긋나면 Enter 를 보내지 않는다. 글자를 넣은 뒤에는 다시 시도하지 않고, 전송을 확인하지 못하면 알린다.
  - `claudeCode.useCtrlEnterToSend` 를 켰으면 Ctrl+Enter 로 보낸다(편집기 settings.json 을 읽는다).
  - **한계**: 입력이 없다고 꼭 자리를 비운 것은 아니라서 화면 공유 중이면 편집기가 앞으로 나와 코드가 보일 수 있다. 한도 안내가 패널에 어떤 글자로 보이는지는 실제 한도 상황에서 확인하지 못했다 —
    글자가 다르면 입력하지 않고 "이어 가기 실패" 알림만 뜬다. 같은 이름의 폴더를 두 창에서 열었거나, 여러 폴더 작업 영역 창·프로필 이름이 제목에 붙은 창이면 대상이 아니다.

## 폰에서 보기 (Tailscale, 기본 꺼짐)

PC 를 켜 둔 채 밖에서 폰으로 사용량을 본다. PC 위젯이 이미 가진 값을 읽기만 하는 화면이라 서비스에 새 조회가 나가지 않고, 로그인 정보는 PC 밖으로 나가지 않는다.

1. PC 와 폰에 [Tailscale](https://tailscale.com) 을 설치하고 같은 계정으로 로그인한다.
2. 위젯 우클릭 메뉴(또는 트레이)에서 **폰에서 보기 (Tailscale)** 를 켠다. 메뉴에 `http://100.x.y.z:47113/열쇠 12자/` 주소가 나온다.
   윈도우가 방화벽 허용을 물으면 허용한다.
3. 폰 카메라로 메뉴의 QR 코드를 찍어 그 주소를 연다(**주소 복사**로 복사해 폰으로 보내거나 직접 입력해도 된다). 홈 화면에 추가해 두면 다음부터 바로 열린다.

- 카드마다 5시간·주간 사용률, 리셋 시각과 남은 시간, 소진 예상이 보인다. 값은 열 때 한 번 받고, 화면을 당겨 새로고침하거나 아래 **새로고침**을 누르면 다시 받는다.
- PC 가 꺼졌거나 위젯·Tailscale 이 꺼져 있으면 "PC 에 연결할 수 없어요"가 뜬다. Tailscale 에 연결돼 있지 않으면 메뉴에 주소 대신 안내 문구가 나온다.
- 주소는 PC 의 Tailscale 주소가 바뀌지 않는 한 그대로다. 열쇠를 바꾸려면 위젯을 끄고 `config.json` 의 `remote_token` 을 지운 뒤 다시 켠다.
- 폰으로 나가는 것은 카드 이름·사용률·리셋 시각·오류 문구뿐이다. 이메일·비용·설정은 나가지 않는다. 주소를 아는 같은 Tailscale 네트워크의 기기는 이 값을 볼 수 있다. 이름을 붙이지 않아 이메일로 보이는 계정은 폰에서 서비스 이름(Claude·Codex)으로 보인다.

## 파일
- `widget.py`: 기록·계산, 계정 추가, pywebview 창과 JS API
- `share.py`: 공유 사용량 나누기 계산(순수 함수)
- `qr.py`: 폰에서 보기 주소의 QR 코드 만들기(순수 함수)
- `providers/`: 서비스 하나 = 파일 하나(`claude.py`, `codex.py`, `gemini.py`). 사용량 읽기, 장애 확인 주소, 계정 추가 방법. 새 서비스는 `providers/__init__.py`의 형식대로 모듈을 만들고 `ALL`에 넣는다
- `web/main.html`, `web/insights.html`: 위젯·인사이트 화면
- `web/remote.html`: 폰에서 보기 화면(읽기 전용)
- `web/common.js`, `web/common.css`: 공통 계산, 숫자 롤링·스프링 모션, 색 토큰
- `install_mac.sh`: 맥 설치(가상환경 + .app 실행 아이콘)
- `widget.spec`, `requirements.txt`, `.github/workflows/release.yml`: 실행파일 빌드와 릴리스
- `tests/`: `python -m unittest discover -s tests`
- `web/icon.ico`: 바로가기 아이콘
- `web/reset.wav`: 리셋 알림음
- `web/fonts/PretendardVariable.woff2`: Pretendard (SIL OFL 1.1, `web/fonts/LICENSE.txt`)

## 데이터
- Claude: `~/.claude/.credentials.json` (Claude Code 로그인) → Anthropic usage API
- Codex: `~/.codex/auth.json` (Codex 로그인) → ChatGPT usage API, 실패 시 Codex 세션 로그
- Gemini: Windows 자격증명 / Mac 키체인(`gemini:antigravity`) → Cloud Code usage API
- 기록/설정: `%APPDATA%\QuotaTank\` (`history.jsonl`, `config.json`, 비용 집계 `cost_cache.json`, 공유 사용량 환산 계수 `share_state.json`, WebView 캐시 `webview\`). 예전 이름 폴더(`AIUsageWidget`)가 있으면 예전 위젯이 꺼진 상태에서 처음 실행할 때 옮긴다
- 비용: `~/.claude/projects/**.jsonl`(응답별 토큰)·`~/.codex/sessions/**.jsonl`(token_count 누적값)을 1시간마다 읽는다. 바뀐 파일만 다시 읽는다.
- 새 버전: `api.github.com/repos/daowle/Quota-Tank/releases/latest` 를 하루 한 번(태그 번호만 본다)
- 장애: `status.claude.com/api/v2/summary.json`(claude.ai·Claude Code), `status.openai.com/api/v2/summary.json`(이름에 Codex 가 든 기능과 Login 만 본다. 다른 제품의 장애는 배지로 띄우지 않는다)
- `config.json`의 `day_reset_hour`(하루가 바뀌는 시각, 기본 6 = 오전 6시. 예전 `day_end_hour` 값은 쓰지 않는다), `poll_sec`, `reset_alert`, `reset_alert_min`, `theme`(auto/light/dark), `auto_resume`, `resume_text`, `panel_resume`(VS Code 패널에도 이어 가기), `menubar_text`(맥 메뉴 막대 숫자), `status_check`(장애 확인), `shared_split`(공유 사용량 나눠 보기), `share_plan`(auto/pro/max5/max20), `remote_view`(폰에서 보기), `cycle_start`·`cycle_times`(사이클 예약, `["08:00", "13:00"]`), `credit_day`·`credit_amount`(API 크레딧 결제일 0~31·한 달 크레딧 100/200), `update_check`(새 버전 알림, 기본 켬), `prices`(모델별 단가 덮어쓰기: `{"모델 이름 앞부분": [입력, 출력, 캐시 읽기, 캐시 쓰기 5분, 캐시 쓰기 1시간]}`, 1M 토큰당 달러) 수정 가능
- `web/common.css`·`common.js`를 고치면 html의 `?v=` 숫자를 올린다(WebView 캐시)
